Abstract

Existing benchmarks for embodied AI are designed around task execution — picking up objects, following instructions, reaching goals — and assume systems that have already been trained on demonstrations. They measure performance on held-out tasks, not the process of learning itself. This paper introduces ATLAS (Autonomous Testing for Learning, Attention, and Survival), a benchmark suite designed for a fundamentally different class of systems: embodied agents that learn about the world from scratch, in real time, without demonstrations. This first volume focuses on navigation and exploration — the foundational capabilities that any mobile embodied system must develop before it can perform higher-level tasks such as object manipulation.

ATLAS evaluates five capabilities that no existing benchmark measures: exploration efficiency (how much of the world the system discovers per unit of action), world model convergence (how fast prediction accuracy stabilizes), adaptive attention (whether the system learns to attend to the right sensor channels and re-attends after change), sensor degradation resilience (behavioral robustness when sensors fail), and memory efficiency (whether stored experiences are useful and whether forgetting preserves the right ones).

The suite is organized in two tiers: Tier 1 benchmarks are purely behavioral and require no internal access to the system under test; Tier 2 benchmarks require the system to expose three standardized signals (prediction error, attention vector, memory retrieval indicator) that any learning system implicitly computes. All benchmarks are specified over physical environments reproducible by any lab with standard equipment.

ATLAS provides the first standardized evaluation framework for autonomous embodied learning, filling a critical gap between task-execution benchmarks (LIBEROLIBEROLiu et al. 1. Introduction

The past three years have produced remarkable advances in embodied AI. Vision-Language-Action models (VLAs) like RT-2 (Brohan et al., 2023), OpenVLA (Kim et al., 2024), and $\pi_0$ (Physical Intelligence, 2024) combine internet-scale pre-training with robotic control to achieve impressive performance on manipulation and navigation tasks. The benchmarks that evaluate these systems — LIBERO (Liu et al., 2023), CALVIN (Mees et al., 2022), SIMPLER (Li et al., 2024), VLABench (Zhang et al., 2025), and others — have become the standard currency of the field, with success rates and task completion scores serving as the primary measures of progress.

Yet these benchmarks share a fundamental assumption: the system has been trained before evaluation begins. LIBERO provides demonstration data. CALVIN provides training environments. VLAs are fine-tuned on thousands of teleoperated trajectories. The benchmarks measure the output of learning — task execution — not the process of learning itself.

This paper addresses a different class of embodied systems: those that learn about the world from scratch, in real time, starting from zero knowledge. These include active inference agents operating under the Free Energy PrincipleFree Energy PrincipleKarl Friston’s framework proposing that living systems minimize prediction error. ATLAS builds on this by evaluating the learning capabilities it predicts. (Friston et al., 2017), curiosity-driven reinforcement learning systems (Pathak et al., 2017; Burda et al., 2019), world-model-based agents (DreamerDreamerHafner et al. (2025). World-model-based RL agent that learns environment dynamics from pixel observations and plans in latent space. (Hafner et al., 2025), JEPA (LeCun, 2022)), and other architectures designed for autonomous exploration and adaptation. These systems face a fundamental evaluation problem: there are no standardized benchmarks for measuring how well an embodied agent learns, as distinct from how well it performs pre-learned tasks.

We introduce ATLAS (Autonomous Testing for Learning, Attention, and Survival), a suite of five benchmarks designed to fill this gap. ATLAS evaluates capabilities that are essential for autonomous embodied intelligence but are not measured by any existing benchmark:

  • Exploration efficiency. Does the system actively seek informative experience, or does it wander randomly? Exploration is the foundation of all autonomous learning — a system that cannot efficiently discover its environment cannot learn about it.
  • World model convergence. How quickly does the system build an accurate predictive model of its environment? Sample efficiency in world-model building determines how fast an agent becomes functional after deployment.
  • Adaptive attention. Does the system learn which sensor channels carry the most information, and does it re-learn when conditions change? Attention allocation across modalities is a core cognitive capability that existing benchmarks do not evaluate because most systems use fixed architectures that fuse all inputs uniformly.
  • Sensor degradation resilience. When a sensor fails or becomes unreliable, does the system detect the degradation and compensate, or does it collapse? This is a safety-critical capability for real-world deployment that is entirely absent from current benchmarks.
  • Memory efficiency. Does the system retain useful experiences and discard irrelevant ones? Memory management under finite capacity determines whether an agent can sustain learning over long deployments.

ATLAS is organized in two tiers. Tier 1 benchmarks are purely behavioral: they require no internal access to the System Under Test (SUT) and can be applied to any embodied agent, including black-box systems. Tier 2 benchmarks require the system to expose three standardized internal signals — prediction error, attention vector, and memory retrieval indicator — enabling deeper mechanistic evaluation. All benchmarks are specified over physical environments that any laboratory can reproduce with standard equipment.

We position ATLAS not as a replacement for task-execution benchmarks, but as a complementary evaluation layer. LIBERO asks: can the robot do the task? ATLAS asks: can the robot learn the task’s world from scratch? Both are necessary for a complete picture of embodied intelligence.

This paper presents Volume I of the ATLAS suite, focused on navigation and exploration. Navigation is the natural starting point for evaluating autonomous embodied learning because it is prerequisite to everything else: a system must first learn to perceive its environment, avoid obstacles, allocate attention across sensors, and build a spatial world model before it can manipulate objects, follow complex instructions, or collaborate with humans. The five benchmarks in this volume — Exploration Efficiency, World Model Convergence, Adaptive Attention, Sensor Degradation Resilience, and Memory Efficiency — are all grounded in the navigation setting, using mobile robots operating in indoor environments. Volume II, planned as future work, will extend the ATLAS framework to manipulation learning: evaluating whether embodied systems can discover object affordances, learn grasping strategies, and develop tool use from scratch.

2. Related Work

2.1 Task-Execution Benchmarks

The dominant paradigm in embodied AI evaluation is task execution. LIBERO (Liu et al., 2023) provides 130 language-conditioned manipulation tasks organized into suites that test transfer across object types, spatial arrangements, and goals. CALVIN (Mees et al., 2022) evaluates language-conditioned manipulation across multiple environment setups. SIMPLER (Li et al., 2024) bridges simulation and reality with environments that correlate strongly with real-world performance. VLABench (Zhang et al., 2025) extends evaluation to semantic reasoning and long-horizon planning. These benchmarks are essential for the VLA paradigm, but they share a structural limitation: they presuppose that learning has already occurred.

For navigation, R2R (Anderson et al., 2018) and its continuous-environment successor VLN-CE (Krantz et al., 2020) evaluate instruction-following in photorealistic indoor environments, using metrics including Success Rate (SR), Success weighted by Path Length (SPL), Navigation Error (NE), and normalized Dynamic Time Warping (nDTW). NaVILA (Cheng et al., 2025) extends these to legged robots with a physics-realistic Isaac Sim benchmark. These benchmarks also assume pre-training on demonstration trajectories.

2.2 Exploration and Curiosity Metrics

Intrinsic motivation and curiosity have been studied extensively in reinforcement learning. Count-based exploration (Bellemare et al., 2016), prediction-error curiosity (Pathak et al., 2017), and Random Network Distillation (Burda et al., 2019) all drive exploration through internal signals. However, these methods are typically evaluated on downstream task performance (Atari scores, MuJoCo rewards) rather than on the quality of exploration itself. There is no standardized benchmark that directly measures exploration efficiency as a first-class metric.

2.3 Consciousness and Awareness Evaluation

The question of evaluating machine consciousness has attracted growing attention. Butlin et al. (2023) derive indicators from neuroscientific theories of consciousness and propose using them to assess AI systems. Evers et al. (2026) outline desiderata for evaluating awareness in artificial systems: any framework should be domain-sensitive, scale-neutral, multidimensional, and ability-oriented. ATLAS shares these desiderata but focuses on operationally measurable capabilities rather than theoretical consciousness indicators.

2.4 Active Inference and Free Energy Benchmarks

The active inference community, building on Friston’s free energy principle (Friston et al., 2017), has produced frameworks for embodied agents that minimize surprise through perception and action. Recent work like EASE (Chen et al., 2025) demonstrates emergent behaviors — implicit memory, target tracking, adaptive control — from free energy minimization alone. However, there is no standardized evaluation suite for comparing active inference agents against other embodied learning systems. ATLAS provides this.

2.5 Lifelong and Continual Learning

LIBERO was originally designed as a lifelong learning benchmark, measuring forward transfer and catastrophic forgetting. In practice, virtually all published results use the full training dataset without continual learning. The lifelong learning dimension remains largely untested. ATLAS’s Memory Efficiency benchmark (Section 4.5) directly addresses this gap.

3. The ATLAS Framework

3.1 Design Principles

ATLAS is governed by five design principles:

  • Architecture agnosticism. The benchmarks test capabilities, not implementations. Any system that can be embodied in a mobile platform with sensors — whether it uses linear models, neural networks, active inference, reinforcement learning, or hybrid architectures — can be evaluated.
  • Zero-shot evaluation. The SUT receives no prior training data, no demonstrations, and no reward functions from the benchmark. Learning occurs entirely during the evaluation itself.
  • Physical reproducibility. Reference environments are specified in terms of physical room layouts, obstacle types, and sensor configurations that any laboratory can recreate with standard equipment.
  • Graduated access. The two-tier structure ensures that any system can participate in at least some benchmarks (Tier 1) while enabling deeper evaluation for systems that expose internal signals (Tier 2).
  • Ablation-friendly. Every benchmark is designed to be informative when comparing a system against ablated versions of itself (e.g., with curiosity disabled, with memory removed, with attention fixed).

3.2 The Two-Tier Structure

Tier 1: Behavioral Benchmarks require no internal access to the system under test. Evaluation is based entirely on observable behavior: where the robot moves, how it responds to environmental changes, and whether it avoids collisions. Any embodied system can be evaluated at Tier 1, including proprietary black-box systems.

Tier 2: Mechanistic Benchmarks require the system to expose three standardized signals at each decision cycle via a simple publish-subscribe interface (Table 1).

These signals are not architecture-specific. An active inference agent exposes variational free energy (prediction_error), precision weights (attention_vector), and posterior updates from episodic memory (memory_retrieval). A Dreamer agent exposes reconstruction loss, encoder attention maps, and replay buffer sampling. A curiosity-driven RL agent exposes intrinsic reward magnitude, feature importance weights, and experience replay flags. The interface asks the system to externalize signals it already computes internally.

3.5 Measurement Units: Time, Distance, and Cycles

Embodied systems operate at widely varying decision frequencies. A wheeled robot may run its perception-action loop at 5 Hz while a drone controller operates at 200 Hz. Using raw action cycles as the unit of measurement would make cross-platform comparison meaningless: 3,000 cycles at 5 Hz represents 10 minutes of experience, while 3,000 cycles at 200 Hz represents 15 seconds.

ATLAS addresses this by selecting the most appropriate physical unit for each benchmark:

  • Distance-normalized metrics are used where the quality of physical interaction matters. The Exploration Efficiency Index reports states discovered per meter traveled, ensuring that a robot covering 10 meters and discovering 15 visual states is scored equally regardless of how many decision cycles or seconds it took.
  • Time-normalized metrics are used where practical deployment speed matters. World Model Convergence reports seconds to convergence, because the operationally relevant question is how long a user must wait after deploying a robot before it becomes competent.
  • Duration-defined protocols specify each experimental phase in wall-clock time (e.g., “3 minutes of autonomous movement”) rather than cycle counts. The SUT executes as many decision cycles as its architecture permits within that duration.

All SUTs must operate at a minimum decision frequency of 2 Hz to ensure meaningful real-time interaction with the environment. Systems must also report their actual decision frequency alongside all results. For single-platform comparisons (e.g., full system vs. ablation on the same robot), cycle-based metrics remain valid and may be reported as supplementary data.

A note on Tier 2 signal comparability. Absolute values of prediction_error depend on the system’s internal architecture — a pixel-prediction model and a latent-dynamics model will produce error values on different scales. Tier 2 metrics are therefore meaningful only for within-system comparisons (e.g., full system vs. ablation, or the same system across environments), not for comparing absolute values across different architectures. Cross-architecture comparison should rely on Tier 1 behavioral metrics and on normalized quantities such as ratios and rank correlations.

4. Benchmarks

4.1 Exploration Efficiency Index (EEI)

Tier: 1 (behavioral, no internal access required)

Motivation

Exploration is the foundation of autonomous learning. A system that cannot efficiently discover its environment cannot learn about it. Yet exploration quality is almost never evaluated directly — it is typically measured indirectly through downstream task performance. EEI measures exploration as a first-class capability.

Metric Definition

The primary metric is the Exploration Efficiency IndexEEIExploration Efficiency IndexRatio of distinct visual states discovered to total distance traveled in meters. Measures how efficiently a system explores its environment., defined as the number of distinct visual states discovered per meter of distance traveled:

$$\text{EEI} = \frac{V_{\text{discovered}}}{D_{\text{traveled}}}$$(1)

where $V_{\text{discovered}}$ is the number of distinct visual states visited and $D_{\text{traveled}}$ is the total distance covered in meters (computed from odometry or integrated velocity commands). Distance normalization ensures fair comparison across platforms with different movement speeds — a fast robot and a slow robot that both discover 15 states per 10 meters of travel receive the same score. A visual state is defined as a cluster centroid in the space of visual representations:

  1. Extract a visual representation from each frame captured during the run using a pre-trained visual encoder that produces fixed-dimensional embeddings. The choice of encoder is left to the researcher and must be reported alongside results. To ensure comparability across studies using different encoders, we recommend that authors also report Spatial Dispersion (SD), which is encoder-independent.
  2. After the run, cluster all embeddings using $k$-means with $k$ selected by silhouette score ($k \in [5, 50]$), or use a fixed $k = 20$ for comparability.
  3. $V_{\text{discovered}}$ is the number of clusters containing at least one embedding from the run.

Sub-Metrics

Time to $N$% Coverage ($T_N$). The wall-clock time in seconds until the SUT has visited $N$% of all discoverable clusters. Discoverable clusters are established by running a random walk baseline for the same duration and taking the union of its clusters with the SUT’s. Report $T_{50}$, $T_{75}$, and $T_{90}$.

Revisit Ratio (RR). The fraction of distance traveled within visual state clusters that have already been visited more than 5 times. Lower is better. A system stuck in a loop has RR approaching 1.0.

Spatial Dispersion (SD). Compute the convex hull area of all positions visited. $\text{SD} = \text{hull area} / \text{environment area}$. This metric requires odometry and is encoder-independent, making it the most robust cross-study comparison point.

Protocol

The EEI is evaluated in Environments B and C. Environment A is excluded because its minimal visual variation (only 2 obstacles, uniform texture) provides too few discoverable states for meaningful differentiation between exploration strategies. Environment B tests exploration in a moderately complex, controlled setting. Environment C adds multi-room connectivity and human presence, testing whether the system’s exploration strategy scales to more challenging conditions.

For each environment:

  1. Place the SUT at the designated starting position (center of the room, facing the longest wall). In Environment C, start in Zone 1.
  2. Initialize with fresh state (no prior training, default parameters).
  3. Run autonomously for 10 minutes. Do not intervene. Record odometry throughout.
  4. Record the visual stream (one frame per decision cycle) and cumulative distance traveled.
  5. Repeat with the random walk baseline (uniform random actions with collision avoidance) for the same 10-minute duration.
  6. Compute EEI, $T_N$, RR, and SD for both conditions.

Report EEI scores for each environment separately. The ratio between Environment C and B scores characterizes how well the exploration strategy scales with environmental complexity.

Baselines and Interpretation

The random walk is the universal lower bound. Any learning system should exceed it; the degree of improvement quantifies the value of the system’s exploration strategy. An EEI ratio (SUT / random walk) above 1.5 indicates meaningfully superior exploration. Additional baselines may include: the same system with exploration mechanisms disabled (ablation), count-based curiosity, or $\varepsilon$-greedy exploration.

4.2 World Model Convergence (WMC)

Tier: 1 (behavioral) + Tier 2 (mechanistic, with prediction_error signal)

Motivation

An embodied learning system’s primary job is to build an accurate model of its environment. The speed at which this model converges determines how quickly the agent becomes functional. This is the embodied equivalent of sample efficiency in reinforcement learning (RL), measured on prediction quality rather than task reward.

Metric Definition

Tier 1 (Behavioral): Collision Rate Convergence (CRC). A system with an accurate world model should collide less over time as it learns spatial relationships. CRC is measured as the wall-clock time (in seconds) until the rolling collision rate drops below a threshold and stays below for at least 30 consecutive seconds. The collision rate is computed as collisions per minute, using a 60-second rolling window. The threshold is 1.0 collision per minute, or the minimum observed rate $\times 1.5$, whichever is higher. Critically, only periods of active movement count: intervals where the SUT’s velocity is below a minimum threshold (0.01 m/s) are excluded from the collision rate calculation. This prevents a system from achieving a low collision rate by simply freezing or moving imperceptibly slowly.

Tier 2 (Mechanistic): Time to ConvergenceT2CTime to ConvergenceThe wall-clock time in seconds until prediction error stabilizes within 20% of its final value. Lower means faster learning. (T2C). T2C is defined as the wall-clock time in seconds from the start of the run until the rolling average of prediction_error (30-second window) stays within 20% of its final value (mean of last 60 seconds) for at least 30 consecutive seconds. Lower is better. If the system fails to converge within the run duration, T2C is recorded as non-convergent.

Sub-Metrics

Final Prediction Floor (FPF). The mean prediction_error over the last 60 seconds. Report T2C and FPF jointly. A system that converges fast to a high floor is worse than one that converges slowly to a low floor. (Tier 2. Within-system comparison only — absolute FPF values are not comparable across architectures.)

Re-Convergence Ratio (RCR). After convergence, introduce a perturbation (rearrange one obstacle by at least 0.5 m). Measure time to re-converge using the same T2C definition. $\text{RCR} = \text{T2C}_{\text{re}} / \text{T2C}_{\text{initial}}$. A ratio below 1.0 indicates the system learned transferable environmental structure rather than memorizing specific sensor patterns.

Generalization Test (GT). After the model converges, stop the SUT and relocate it to a position in the environment it has not previously visited (at least 1.5 m from any previously occupied position, verified via odometry). Resume the run for 60 seconds. Measure mean prediction_error over this period and compare to the Cold Start control’s mean prediction_error over its first 60 seconds at the same location. If the converged model’s error is lower than the cold start’s, the system has learned generalizable structure; if it is equal or higher, the model was overfitting to locally visited regions. Report the Generalization Ratio: $\text{GR} = \overline{F}_{\text{cold}} / \overline{F}_{\text{relocated}}$; values above 1.0 indicate positive generalization. (Tier 2.)

Per-Channel Convergence. If per-channel prediction error is available, report T2C separately for each sensor modality. This reveals whether some modalities are learned faster than others. (Tier 2.)

Protocol

Run the SUT in each reference environment (A, B, C) for 20 minutes each, starting from fresh state. Record prediction_error at each decision cycle (Tier 2) and/or collisions via IMU or external observation (Tier 1). After convergence, apply one perturbation (move a single obstacle at least 0.5 m) and continue for 5 additional minutes to measure re-convergence. Then apply the Generalization Test by relocating the SUT to an unvisited position.

4.3 Adaptive Attention Gauntlet (AAG)

Tier: 2 (requires attention_vector signal)

Motivation

Any system processing multiple sensor modalities must allocate processing resources across them. A camera in a dark room provides no useful information; a LiDAR in an open field provides little variation. The optimal allocation changes with context. This benchmark tests whether a system learns the right allocation and re-learns when conditions change.

Metric Definition

Attention AccuracyAAAttention AccuracySpearman rank correlation between ground-truth sensor informativeness and the system’s learned attention allocation. Ranges from −1 (wrong) to +1 (perfect). (AA). Before the test, a panel of evaluators defines the ground-truth informativeness ranking of sensor channels for each phase. AA is the Spearman rank correlation ($\rho$) between the ground-truth ranking and the attention_vector ranking, computed over the last 30 seconds of each phase and averaged across all phases:

$$\text{AA} = \frac{1}{P} \sum_{p=1}^{P} \rho\!\left(\text{ranking}_{\text{gt},p},\; \text{ranking}_{\text{attn},p}\right)$$(2)

AA ranges from $-1.0$ (systematically wrong) through $0.0$ (random) to $+1.0$ (perfect).

Protocol: The Gauntlet

The SUT begins with fresh state in Environment B and runs continuously through all phases without restart. Each phase changes a single environmental variable. Phase durations are specified in wall-clock time; the SUT executes as many decision cycles as its architecture permits within each phase.

Sub-Metrics

Re-Adaptation Speed (RAS). Wall-clock seconds after a phase transition before $\rho > 0.5$ is sustained for at least 10 consecutive seconds. Lower is better.

Attention Entropy (AE). Shannon entropy of the normalized attention_vector. High entropy = uniform (no specialization); low entropy = concentrated. Report mean AE per phase.

4.4 Sensor Degradation Resilience (SDR)

Tier: 1 (behavioral, no internal access required)

Motivation

Real-world robots have sensors that fail. A robust system should detect degradation and compensate by relying on functioning sensors. This is a safety-critical capability entirely absent from current benchmarks.

Metric Definition

$$\text{Resilience Ratio} = \frac{\text{Performance}_{\text{degraded}}}{\text{Performance}_{\text{healthy}}}$$(3)

where Performance is a composite measured over a 90-second window of active movement:

$$\text{Performance} = \frac{\text{ActionDiversity} + \text{CollisionAvoidance} + \text{Mobility}}{3}$$(4)
  • Action Diversity: fraction of discrete action bins visited (normalized to $[0,1]$).
  • Collision Avoidance Rate: $1 - (\text{collisions} / \text{minutes of active movement})$, normalized to $[0,1]$.
  • Mobility: fraction of the measurement window spent with non-zero velocity.

A Resilience RatioRRResilience RatioRatio of degraded performance to healthy performance. 1.0 means no impact from sensor failure; 0.0 means total collapse. of 1.0 means zero behavioral impact. A ratio of 0.0 means total collapse.

Protocol

  1. Run the SUT for 7 minutes to establish baseline $\text{Performance}_{\text{healthy}}$.
  2. Apply each degradation for 3 minutes, followed by a 90-second recovery period with the sensor restored:
DegradationMethodWhat It Tests

Recovery Metric

Recovery Time (RT). Wall-clock seconds after sensor restoration until Performance returns to within 90% of baseline. Fast recovery demonstrates temporary adaptation, not permanent model corruption.

4.5 Memory Efficiency (Loop Test)

Tier: 2 (requires memory_retrieval signal)

Motivation

An embodied system operating over long timescales must decide what to remember and what to forget. The Loop Test directly measures whether stored experiences from a first visit to an environment help during a second visit.

Protocol: The Loop

Prepare two visually distinct zones (Zone A and Zone B) separated by at least 2 meters.

  1. Phase 1 (First Visit): Fresh state. Zone A for 7 minutes.
  2. Phase 2 (Displacement): Stop. Move SUT to Zone B. Resume for 7 minutes.
  3. Phase 3 (Return): Stop. Move SUT back to Zone A (same position as Phase 1). Resume for 7 minutes.
  4. Control: Fresh-state SUT in Zone A for 7 minutes (Cold Start baseline).

Metric Definition

Memory Utility ScoreMUSMemory Utility ScoreProduct of memory retrieval rate and retrieval quality. Measures whether stored experiences actually help on return visits. (MUS):

$$\text{MUS} = R_{\text{rate}} \times R_{\text{quality}}$$(5)

where $R_{\text{rate}}$ is the fraction of the first 90 seconds of Phase 3 where memory_retrieval $= \text{True}$, and $R_{\text{quality}}$ is the fraction of those retrieval moments where prediction_error at the next decision step is lower than the Cold Start control’s mean at the equivalent elapsed time.

Sub-Metrics

Forward Transfer Ratio (FTR). $\text{FTR} = \text{AUC}_{\text{cold}} / \text{AUC}_{\text{return}}$ over the first 3 minutes of Phase 3 vs. the first 3 minutes of the Cold Start control, where AUC is computed over the prediction_error time series. $\text{FTR} > 1.0$ indicates positive transfer.

Negative Transfer Check. $\text{FTR} < 1.0$ flags a memory system that harms performance on return.

Pruning Quality (PQ). If the memory buffer reaches capacity during Phase 2, MUS in Phase 3 tests whether pruning preserved high-value Phase 1 memories.

5. Beyond the Benchmarks

5.1 What ATLAS Does and Does Not Measure

ATLAS measures learning capabilities — the ability to explore, model, attend, withstand, and remember. It does not measure task execution, instruction following, or manipulation skill. A system that scores perfectly on ATLAS might still be unable to pick up a mug. Conversely, a system that scores perfectly on LIBERO might fail every ATLAS benchmark if it cannot learn without demonstrations. The two evaluation paradigms are complementary.

5.2 Applicability Across Architectures

ATLAS is designed to be useful for a broad range of embodied learning architectures:

  • Active inference agents (free energy principle): prediction_error = variational free energy; attention_vector = precision weights; memory_retrieval = posterior update from episodic model.
  • World-model-based RL (Dreamer, RSSM): prediction_error = reconstruction loss; attention_vector = gradient-based attribution per modality; memory_retrieval = experience replay flag.
  • Curiosity-driven RL (ICM, RND): prediction_error = intrinsic reward signal; attention_vector = per-modality curiosity; memory_retrieval = prioritized replay sampling.
  • VLAs in continual learning: If adapted for online learning, VLAs can participate in Tier 1 immediately and Tier 2 if they expose loss and attention signals.
  • Biological systems: Tier 1 benchmarks could in principle be applied to animal behavior studies (e.g., rodent exploration in novel mazes).

5.3 Limitations

Ground-truth subjectivity in Benchmark 3. The Attention Gauntlet requires evaluators to define informativeness rankings. While the phases are designed to make the correct ranking obvious, there is room for disagreement. We recommend at least two independent evaluators.

Physical reproducibility. Environments will vary across labs. We recommend focusing on relative comparisons (system vs. ablation) rather than absolute values. Simulation equivalents are planned for future versions.

Decision frequency dependence. While ATLAS specifies protocols in wall-clock time and physical distance to enable cross-platform comparison, the number of learning updates a system performs within a given duration still depends on its decision frequency. Systems must report their actual decision frequency alongside results, and a minimum frequency of 2 Hz is required.

Manipulation-capable systems. The current suite focuses on mobile navigation and exploration. Future extensions should add manipulation learning benchmarks.

5.4 Relationship to Consciousness Evaluation

ATLAS does not claim to measure consciousness. It evaluates operationally defined capabilities that are prerequisites for any theory of machine consciousness but are not sufficient for it. A system that cannot explore, learn, attend, or remember is unlikely to be conscious by any theory. ATLAS provides the empirical foundation on which consciousness evaluations can be built.

5.5 Future Directions

Simulation environments. The most significant limitation of physical-only evaluation is reproducibility: every lab’s Environment B will differ in exact obstacle placement, lighting conditions, and visual texture. Standardized simulation equivalents in Gazebo, Isaac Sim, and ManiSkill would enable automated, deterministic evaluation at scale. The challenge is ensuring that simulation-based scores correlate with physical-world scores — a problem that the SIMPLER benchmark (Li et al., 2024) has shown is solvable through careful visual matching and system identification. We envision a future version of ATLAS that specifies both physical and simulated environments, with paired validation studies establishing the correlation between them. This would allow rapid iteration in simulation while retaining the physical environments as ground-truth validation.

Multi-agent benchmarks. When multiple autonomous learning systems share an environment, their interactions create a fundamentally different learning problem. One agent’s actions become another’s sensory input, creating coupled dynamics that neither agent individually controls. Key questions include whether mutual prediction pressure produces cooperative or competitive behavior, whether inter-agent communication emerges from shared optimization objectives, and whether collective exploration is more efficient than independent exploration. A multi-agent extension of ATLAS would place two or more SUTs in the same environment and measure whether joint EEI exceeds the sum of individual EEIs, whether the presence of another learning agent accelerates or impedes world model convergence, and whether attention systems learn to track the other agent as a distinct entity.

Manipulation learning. The current ATLAS suite focuses on mobile navigation and exploration because these capabilities are prerequisite to manipulation: a system must first learn to perceive and move through its environment before it can learn to interact with objects. However, extending ATLAS to manipulation-capable platforms (robot arms, mobile manipulators) would enable evaluation of object interaction learning from scratch — for example, whether a system can discover that pushing an object changes its position, or that grasping requires specific approach angles, without being told. This would bridge the gap between ATLAS (learning evaluation) and LIBERO (manipulation evaluation).

Cross-embodiment transfer. Can a world model learned on one robot body transfer to another? If a wheeled robot and a legged robot both learn in the same environment, do their world models share transferable structure (physics of obstacles, visual correlations) despite having different action spaces and sensor configurations? This question is increasingly relevant as the robotics community pursues general-purpose foundation models. An ATLAS cross-embodiment extension would run the Memory Efficiency Loop Test across two different robot platforms: learn in Zone A on Robot 1, then test recall on Robot 2 in the same Zone A. Positive transfer would indicate that the learned world model captures environment structure independent of embodiment.

Longitudinal evaluation. ATLAS currently measures single-session learning over minutes to hours. Real-world deployment requires learning that persists and compounds over days, weeks, and months. A longitudinal version of ATLAS would track key metrics (EEI, T2C, AA, MUS) across multiple sessions with persistent memory, testing whether the system improves indefinitely, plateaus at a stable competency, or degrades over time due to catastrophic forgetting or model drift. This is the most ambitious extension and requires solving the persistent memory problem — saving and restoring learned state across sessions — which remains an open engineering challenge for most embodied learning architectures.

6. Conclusion

We have introduced ATLAS, a benchmark suite for evaluating embodied systems that learn about the world from scratch. Its five benchmarks — Exploration Efficiency, World Model Convergence, Adaptive Attention, Sensor Degradation Resilience, and Memory Efficiency — test capabilities that are fundamental to autonomous embodied intelligence but absent from existing evaluation frameworks.

ATLAS fills a specific gap: the space between task-execution benchmarks (which assume prior training) and theoretical consciousness metrics (which lack operational definitions). By providing standardized, reproducible protocols with clearly defined metrics, ATLAS enables direct comparison across architectural paradigms — active inference, curiosity-driven RL, world-model-based agents, and beyond — on capabilities that matter for real-world autonomous deployment.
